# 고려 장인 공방

초등학교 5학년이 고려청자와 팔만대장경을 장인의 순서대로 직접 만들어 보는 체험 웹앱입니다.

- **청자 공방 (8단계)**: 흙 거르기 → 모양 빚기 → 말리고 다듬기 → 상감 ① 무늬 파내기 → 상감 ② 다른 색 흙 채우기 → 초벌구이와 유약 → 재벌구이 → 완성
- **대장경 공방 (8단계)**: 나무 고르기 → 나무 손질 → 판 다듬기 → 틀린 글자 바로잡기 → 글자 새기기 → 마무리 → 장경판전에 보관 → 완성

## 실행

`index.html` 파일 하나로 동작합니다. 브라우저에서 바로 열거나, GitHub Pages로 배포하면 됩니다. 글꼴만 Google Fonts에서 불러옵니다.
